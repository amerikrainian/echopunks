1. A Note Before Starting

Turn off the Steam overlay for EXAPUNKS (hit manage on the game in your Steam library, Properties, General, uncheck "Enable the Steam Overlay while in-game"). It steals focus and keystrokes.

2. Groups and items

Every screen the mod understands is laid out the same way, and once you have this, you have most of the mod:

  • A screen is a row of groups (also call them stops). Tab moves to the next group, Shift+Tab to the previous one. When you land on a group, you hear its name and then the item you're on.
  • Inside a group, Up and Down walk the items. Home and End jump to the first and last. Where items sit side by side (tabs, a row of buttons, a grid), Left and Right move along the row.
  • Enter activates the item: presses the button, opens the task, picks the card.
  • Backspace is the secondary action, where there is one: delete a solution, delete an EXA, put a card back, close a popup.
  • Space reads the game's own tooltip for the item, if the game has one.
  • Some longer groups are split into regions (a chat log versus the user list, cycles in a log). Ctrl+Up and Ctrl+Down jump between regions.

The mod remembers where you were in each group, so tabbing away and back puts you on the same item.

3. The room

The title screen is your room, with a couple of things you can use: the computer (SAWAYAMA Z7 TurboLance), which takes you to the desktop where the game lives, and the tablet (TEC Constellation II), which is the control panel (settings). Later in the story a third item, TRASH WORLD NEWS, joins them.

4. The desktop

The desktop is the game's hub. Here's some of the groups found on it.

  1. AXIOM PERSONAL ORGANIZER: your task list.
  2. Task details: the selected task's title, date, description, location or network, and action buttons.
  3. CHATSUBO: the chat window. No, you can't actually reply to these nice folks.
  4. Programs: You'll just have to see what shows up here as you go through the game.

5.2. Reading a network

Consider five hosts:

  • YOU, with link 800 to A.
  • A, with link -1 back to YOU, link 800 to B, and link 801 to D.
  • B, with link -1 back to A and link 800 to C.
  • C and D, with no further links.

Go to Hosts, arrow to A, and Tab once. You're in "A links":

-1, YOU
800, B
801, D

Enter on "800, B" travels the link, as if you'd run LINK 800: B becomes the selected host and you're now in "B links". So:

  • LINK 800, LINK 800 puts you at B.
  • LINK 800, LINK 801 puts you at D, and you're stuck there.
  • LINK 800, LINK 800, LINK 800 puts you at C, stuck again.

On links and hosts you'll also hear:

  • "One way": no link back from the other side.
  • "blank" instead of a number: the connection is drawn with an empty number plate.
  • "locked": the connection is drawn but closed for now.
  • "Unnamed host 4": a host drawn without a name, numbered by its position in Hosts.

5.3. Windows

An EXA row reads its name, host and registers; while running, also its next instruction and any error. REPL copies get their own rows ("XA:1") after their parent. Right from an EXA goes to its M-bus toggle, then its Name field (yes, only two characters).

  • Enter: open the EXA's code.
  • Backspace: delete the EXA.
  • Shift+Up/Shift+Down: move the EXA in the list. The order decides who goes first when EXAs compete in the same cycle.

Enter on a file row, here or in a host, opens its values one per line. Escape or Backspace closes it.

5.4. Writing code

The Code group is a normal text field. Lines are limited to 24 characters (not my choice). Ctrl+Up/Ctrl+Down switch to the previous or next EXA's program, and Ctrl+Enter creates a new EXA. Tab leaves the field.

Compile errors appear in the Problems group; Enter on one puts the cursor on its line.

5.5. Running and stepping

  • F2: step one cycle. It reads the cycle and what each EXA is about to do: "Cycle 4. XA: LINK 800".
  • F3: pause. F4: run. F5: fast-forward.
  • Escape: reset the run.

Stepping speaks every error and goal change. A free run speaks only goal failures; the rest is in the logs.

5.6. Checking registers

Outside text fields, X, T, F and M read that register of the focused EXA: the one whose window row you're on, otherwise the one whose code you were last in.

5.7. Following execution

While running, the code field is read-only: arrows read lines, and the line an EXA is about to execute is marked "current". Alt+Up/Alt+Down switch between live copies of the program; Enter on a copy's row in Windows does the same.

5.8. Running to a line

  • F8 in the code field: run until any copy of the program reaches the cursor's line.
  • Shift+Enter: run until one EXA reaches it (the one you're following in the code field, or that row's EXA in Windows).

5.9. The goal

Show Goal (or F1) opens a popup of the finished state: files, values, hardware. Enter on a file opens its values. Tables are walked like tables: Up/Down within a column, Left/Right across.

5.10. Test runs and solutions

Test Run picks which of the 100 test runs you start from: Left/Right by one, Page Up/Page Down by ten, Enter to type a number.

The solution browser (Ctrl+O): Enter opens a solution, Backspace deletes it without asking.

5.11. Things worth knowing

  • EXAs that aren't yours are "other EXA", or "enemy EXA" in battles.
  • A file held by someone else's EXA has no number on screen; the host says "other EXA holding a file".
  • Ctrl+Z also undoes the mod's deleting, reordering and renaming.

6. Everything else on the desktop

6.1. ПАСЬЯНС

Left/Right between columns, Up/Down within one. Enter picks up a card and everything on top of it; Enter on a destination drops it; Backspace puts it back.

6.2. The Redshift sandbox

The editor plus a sprite group (Enter toggles a pixel), a 2D/3D switch and, while running, a Screen group listing what's drawn. While a program free-runs, every key goes to the game for the pad (default W A S D, J K L, Enter for Start; rebind in the control panel). F3 gives you the keyboard back.

6.3. Axiom VirtualNetwork+

Remote (Workshop) and Personal (your own scripts) tabs. Enter plays, Backspace deletes, the Actions group has the rest.

6.4. HACK*MATCH

Not accessible, and not planned, as it is basically Tetris and would require complete reimagining for audio.
