# Changelog

## V0.1.4

- Goal popups that deal with a table of values render them as an actual table rather than an n-tuple of values.
- The TRASH WORLD NEWS digital versions now open as HTML pages in your browser.
- Aligned the histograms as one stop

## V0.1.3

- Moss recalls how the editor is laid out during the Ghast visit that hands over the zine.

## V0.1.2

- EXAs can be renamed... though the game only allows for only 2 letter monikers.
- Trash World News now ships as text documents. The Digital Version button on each issue opens the zine in your text editor instead of the game's locked PDF.

## V0.1.1

- Pressing enter on the items in the first task of the game now spells out the item for the illiterates out there. Hey, I mean I technically am, I can say these things, right?
- Global keys to check currently focused EXA registers, each following the respective registers: X, T, M and F.
- Scrolling over the EXA in the windows row automatically puts your focus on them, meaning that future steps, register keys, all will act as if you're watching the EXA under your cursor.
