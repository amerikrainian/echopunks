# The Desktop

The desktop is the game's hub. Here's some of the groups found on it.

1. **AXIOM PERSONAL ORGANIZER**: your task list.
2. **Task details**: the selected task's title, date, description, location or network, and action buttons.
3. **CHATSUBO**: the chat window. No, you can't actually reply to these nice folks.
4. **Programs**: You'll just have to see what shows up here as you go through the game.
