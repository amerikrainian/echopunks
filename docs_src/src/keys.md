# Key Reference

## Everywhere

| Key | What it does |
|---|---|
| Tab / Shift+Tab | Next / previous group |
| Up / Down | Previous / next item |
| Left / Right | Move along a row; adjust a slider |
| Home / End | First / last item |
| Page Up / Page Down | Adjust a slider by a large step |
| Ctrl+Up / Ctrl+Down | Previous / next region |
| Enter | Activate |
| Backspace | Secondary action: delete, put back, close a popup |
| Space | Read the game's tooltip |
| F6 | Echo typed characters on / off |
| Ctrl+F2 | Step Narration: Focused EXA / All EXAs |

## EXA Editor

| Key | What it does |
|---|---|
| Alt+1 to Alt+6 | Jump to Task, Windows, Hosts, Code, Test log, Solution |
| F2 | Step one cycle |
| F3 / F4 / F5 | Pause / run / fast-forward |
| F1 | Goal popup |
| F8 | Run to the cursor's line, any copy |
| Shift+Enter | Run to the line, one EXA |
| X / T / F / M | Read the focused EXA's register |
| Ctrl+Up / Ctrl+Down | In the code field: previous / next EXA program |
| Alt+Up / Alt+Down | While running, in the code field: previous / next live copy |
| Ctrl+Enter | In the code field: new EXA |
| Ctrl+O | Solution browser |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Shift+Up / Shift+Down | On an EXA in Windows: move it up / down |
| Escape | Close a popup; otherwise reset the run |

## Cutscenes

| Key | What it does |
|---|---|
| Space, Tab or Enter | Next line |
| Escape | Skip the scene |
| 1 to 9 | Pick an EMBER reply |
